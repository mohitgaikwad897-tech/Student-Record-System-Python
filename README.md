A beginner-friendly **Student Record Management System** built using **Python** and **File Handling**.

---

## 📖 About the Project

This project is a menu-driven Student Record System developed in Python. It stores student details in a text file and allows users to perform basic operations like adding, searching, updating, deleting, sorting, and exporting student records.

The project was created as a mini project to practice Python fundamentals and file handling concepts.

---

## ✨ Features

- ➕ Add Student
- 👀 View All Students
- 🔍 Search Student by Roll Number
- ✏️ Update Student Marks
- 🗑️ Delete Student by Name or Roll Number
- 📊 Sort Students by Marks
- 🎯 Display Students Scoring More Than 75
- 🏆 Export Top 3 Students
- 💾 Backup Student Records
- 📈 Count Students Above 90 and Below 35
